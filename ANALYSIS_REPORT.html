Что анализировали

Экспорт избранного Telegram (result.json, 1731 сообщение). Отсеяны личные промпты, логи Termux/SSH, всё по iikoinvoicebot. Оставлены пересланные посты из AI-каналов и сохранённые ссылки.

Главный вывод

Внешние идеи — не «новое направление», а дозаполнение уже начатого AI Native workspace. Проект уже имеет memory bank, skills, bridges, dashboards — осталось мультиагентность, semantic testing, sandbox, VPS.

Как реализовано в PythonProject

Продуктовая архитектура

Telegram / MAX bot → POST /process | /process-batch → data/jobs/<id>/payload.json → RQ queue (Redis) → worker: process_invoice_task() → InvoicePipelineService → recognition_race (OpenAI vision ∥ SotaOCR) → LLM parse → iiko API | CSV/XLSX → уведомление пользователю

Backend

app/api.py — FastAPI, webhook, metrics middleware

Worker

app/tasks.py — RQ, Telegram edit/send

Pipeline

app/services/pipeline.py — OCR → LLM → iiko

Telegram

app/bot/manager.py — aiogram, post-recognition UX

MAX (активно)

experiments/max_invoice_bot/ — task_watcher poll

Observability

app/observability.py — metrics.jsonl, alerts
